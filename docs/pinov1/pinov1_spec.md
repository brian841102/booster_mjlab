## 4. 仿真里实际用了多少（Exp 32@2000，64 台，各指令 8 s，取后 6 s）

> ⚠️ **更正（2026-11-06）**：本节最初版本的数字来自一个有错的脚本——play 配置把横向速度指令放宽成 0~0.1 m/s（给 viser 摇杆用），脚本没设回 0，机器人一直收到训练里没有的横向指令（脚踩直排轮横移，后轮狂转）。原先写的"后轮 p99 150~170 rad/s、大幅打滑"、"手臂 RMS 3.3~4.8 N·m 超额定"都是这个错误造成的，已作废。下表为修正后的重测。

| 指令 | 手臂 2806：\|速度\| p99；\|力矩\| p99 / 最大；最差 RMS | 腿 + 腰 5020：同左 | 后轮 5016：同左 |
|---|---|---|---|
| 站立 | 0.0；0.4 / 0.4；0.4 | 0.0；3.5 / 5.6；3.9 | 0.9；0.3 / 0.4；0.3 |
| 前进 0.6 m/s | 1.6；0.6 / 0.7；0.5 | 1.5；3.8 / 5.9；3.9 | **18.2**；0.7 / 1.1；0.4 |
| 前进 0.9 m/s | 2.0；0.6 / 0.8；0.5 | 1.9；3.6 / 5.2；3.1 | **24.6**；0.9 / 1.5；0.5 |
| 0.9 m/s + 转 0.9 rad/s | 1.9；0.6 / 0.9；0.5 | 1.9；6.0 / 9.8；5.8 | **26.4**；1.2 / 6.4；0.8 |
| 原地转 0.9 rad/s | 1.0；0.5 / 12.0；0.9 | 1.0；5.5 / 24.2；6.9 | 8.8；1.0 / 2.5；0.9 |
| 后退 −0.5 m/s | 0.8；0.5 / 0.6；0.5 | 0.8；3.8 / 9.2；4.5 | 14.5；0.5 / 1.1；0.3 |

（单位：速度 rad/s，力矩 N·m；"最差 RMS" = 各台各关节 6 s 内力矩 RMS 的最大值。纯滚动所需后轮转速：0.6 m/s ≈ 12、0.9 m/s ≈ 18 rad/s。）

**发现（修正后）**：
1. **后轮只在高速时略超 48 V 上限**：0.9 m/s 时 p99 24.6、0.9 m/s 加转弯 26.4 rad/s（上限 ≈ 23.2）；0.6 m/s 18.2、后退 14.5、原地转 8.8，都在上限内。比纯滚动快约 1.3~1.5 倍（有些打滑），但不是先前说的 8~10 倍。
2. **手臂、腿的力矩都远低于连续额定**：手臂最差 RMS ≤ 0.9 N·m（2806 额定 3），腿 / 腰 ≤ 6.9 N·m（5020 连续 9~10）；只有原地转时偶有尖峰（手臂 12、腿 24 N·m）。
3. 腿 / 腰速度 ≤ ~2 rad/s（p99），手臂 ≤ 2 rad/s，远低于上限。
4. T-N 包络（出力象限，超 1.05 倍）：除原地转后轮 0.2% 外均为 0%。

## 5. PD 增益

### 5.1 文献做法（BeyondMimic arXiv 2508.08241；OmniXtreme arXiv 2602.23843；mjlab / unitree_rl_lab 的 G1）

kp = I·ωn²，kd = 2·I·ζ·ωn，I = 电机反射惯量，ωn = 2π·10 Hz，ζ = 2（过阻尼，补偿未计入的连杆惯量）；动作缩放 = 0.25 × 峰值扭矩 / kp。套到 pinov1：

| 电机 | 反射惯量 | kp | kd | 动作缩放 0.25·τ/kp（rad） |
|---|---|---|---|---|
| 2806（手臂） | 5.52e-3 | 21.8 | 1.39 | 0.138 |
| 5020（腿 / 腰） | 1.94e-3 | **7.6** | 0.49 | 1.37 |
| 5016（后轮，速度控制不适用） | 1.50e-3 | — | — | — |

**5020 套公式只得到 kp 7.6**：pinov1 腿是 17 减速、电机惯量小，而连杆 / 机身惯量大（见下表髋 pitch 0.14 kg·m²），只用电机惯量会严重低估；腿用这组增益几乎没有刚度（42 N·m / 7.6 = 5.5 rad 才饱和），不适合直接套用。

### 5.2 含连杆惯量的实际带宽与阻尼比

用默认姿态、浮空时的质量矩阵对角元作为有效惯量 I_eff（支撑腿时髋要带动整个机身，有效惯量更大、带宽更低，所以下表是上限）。频率 f = √(kp / I_eff) / 2π，ζ = kd / (2√(kp·I_eff))；"目标"一栏按 ζ = 0.7 反推 kp = I_eff·(2πf)²、kd = 2·0.7·I_eff·2πf。

| 关节（电机） | I_eff（kg·m²） | 目前训练 PD → f / ζ | 目标 6 Hz、ζ 0.7 | 目标 8 Hz、ζ 0.7 |
|---|---|---|---|---|
| 髋 pitch（5020） | 0.1435 | 50 / 0.5 → 3.0 Hz / 0.09 | 204 / 7.6 | 363 / 10.1 |
| 髋 roll（5020） | 0.1375 | 50 / 0.5 → 3.0 Hz / 0.10 | 195 / 7.3 | 347 / 9.7 |
| 髋 yaw（5020） | 0.0084 | 50 / 0.5 → 12.3 Hz / 0.39 | 11.9 / 0.44 | 21.1 / 0.59 |
| 膝（5020） | 0.0314 | 50 / 0.5 → 6.4 Hz / 0.20 | 44.6 / 1.66 | 79.3 / 2.21 |
| 踝 pitch（5020） | 0.0105 | 50 / 0.5 → 11.0 Hz / 0.35 | 14.9 / 0.55 | 26.5 / 0.74 |
| 躯干 yaw（5020） | 0.0753 | 50 / 0.5 → 4.1 Hz / 0.13 | — | — |
| 肩 pitch（2806） | 0.0169 | 18 / 0.8 → 5.2 Hz / 0.73（50 / 0.5 → 8.7 Hz / 0.27） | 24.0 / 0.89 | 42.6 / 1.19 |
| 肩 roll（2806） | 0.0191 | 18 / 0.8 → 4.9 Hz / 0.68（50 / 0.5 → 8.2 Hz / 0.26） | 27.1 / 1.01 | 48.2 / 1.34 |
| 肩 yaw（2806） | 0.0061 | 18 / 0.8 → 8.7 Hz / 1.21 | 8.6 / 0.32 | 15.3 / 0.43 |
| 肘（2806） | 0.0077 | 18 / 0.8 → 7.7 Hz / 1.07（50 / 0.5 → 12.8 Hz / 0.40） | 10.9 / 0.41 | 19.4 / 0.54 |

### 5.3 建议

| 部位 | 建议 | 理由 |
|---|---|---|
| 腿 / 踝 / 腰（5020） | **维持 50 / 0.5**（已验证可学会站立与交替，Exp 18 起） | 套公式（7.6）太软；xdream.py 的 40 / 3 在 Exp 1~17 训不起来（但当时轮子增益也同时不同，未单独验证 kd）。髋 pitch / roll 在 50 / 0.5 下 ζ ≈ 0.1（欠阻尼），若实机抖动，优先试 **加大 kd**（例 50 / 1.5~3，ζ ≈ 0.3~0.5）而不是降 kp——需单独实验。 |
| 手臂（2806） | 两档：**18 / 0.8**（现况，5 Hz、ζ 0.7，最省电）或 **~27 / 1.0**（肩 6 Hz、ζ 0.7；肘 / 腕 / 肩 yaw 同一组时 ζ > 1 偏过阻尼，也可分组 肩 pitch / roll 27 / 1.0、肩 yaw / 肘 / 腕 11 / 0.4） | 用户觉得 18 / 0.8 太软；kp 再往上（如 45）带宽 8 Hz，但 τ/kp 只剩 0.27 rad 就饱和，且手臂 RMS 已超额定 3 N·m，更硬会更热。 |
| 后轮（5016） | 速度控制；kd 取 峰值 / 最高转速 ≈ 1.5 时上限内可用满力矩（Exp 34 用 1.0、随机 ×0.8~1.2） | 修正后的测量显示后轮只在 0.9 m/s 时略超 23 rad/s；kd 0.5 配 ±23 rad/s 目标裁剪时最多只有 11.5 N·m。 |

**前提**：训练 PD 必须等于实机驱动端设定（nemov3 Exp 78：不一致时实机剧烈振动）。

## 6. 建议的建模方式（依重要性）

1. **后轮转速上限与力矩-转速包络**（修正后的测量：只在 0.9 m/s 时略超上限；Exp 33 起已把轮速目标裁到 ±23 rad/s）：
   - 轮速目标裁到电机能力内（48 V：|ω| ≤ ~23 rad/s；纯滚动 0.9 m/s 只需 18 rad/s、1.15 m/s 需 23 rad/s）。
   - 加 T-N 包络：可用力矩 = 插值（实测 T-N 表），超过最高转速时为 0（OmniXtreme 式 4 / 5 的做法：同向 τ 上限、反向刹车上限、|v| > vx1 后线性降到 vx2）。粗略分段线性拟合（48 V；5016 / 5020 由 72 V 曲线转速 × 2/3 估算）：5016 ≈ 33.6 N·m 到 ~8 rad/s，之后线性降到 ~23 rad/s 时 0；5020 ≈ 42 N·m 到 ~7 rad/s，降到 ~24 rad/s 时 0；2806 ≈ 12 N·m 到 ~2 rad/s，降到 ~21 rad/s 时 ~0。（精确建模建议直接用实测表插值，并在 48 V 实测确认。）
   - 实机母线电压 48 V（已确认）：5016 / 5020 的最高转速约为手册的 2/3。
2. **关节速度上限（48 V）**：2806 23.0 rad/s、5020 ≈ 25.1 rad/s、5016 ≈ 23.2 rad/s（空载峰值；带载更低，由 T-N 包络自然处理）。仿真里只有后轮超出。
3. **部署 PD**（上节）。
4. **控制延迟**：nemov3 实机最好的是执行器 + 指令合并延迟 0~50 ms、每 episode 抽一次（Exp 83 / 85）；OmniXtreme 用 0~15 ms。ENCOS 为 CAN 1M / 5M，需量测实机链路。
5. **热 / 连续扭矩**：修正后的测量显示手臂、腿的 RMS 力矩都在额定内（Exp 32）；仍建议评估中保留各关节 RMS 力矩对照额定值，并留意原地转时的尖峰。
6. **摩擦**：手册未给；XML frictionloss 0.001 几乎为 0。可照 OmniXtreme 加 τ − μs·tanh(v / vact) − μd·v 并随机化，或上机实测（恒速驱动量摩擦力矩）。
7. **躯干质量 ±1 kg、IMU 偏差**：见 `tools/pinov1_finetune.md`「上机准备」。
